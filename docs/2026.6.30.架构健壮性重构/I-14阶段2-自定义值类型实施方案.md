# I-14 阶段 2：自定义值类型实施方案

> 目标：移除 `Emuera.Headless` 对 `System.Drawing.Common` 的依赖
> 方案：创建自定义值类型 + 隐式转换，兼容现有代码
> 预计工作量：2-3 天
> 日期：2026-07-02

## 一、背景

### 1.1 问题

`Emuera.Headless` 项目依赖 `System.Drawing.Common` NuGet 包，主要原因：

1. `IConsoleUI` 接口使用 `System.Drawing.Point/Rectangle/Color/Size`
2. 共享源码（`Shared/` 目录）大量使用这些类型
3. 37 个文件、382 处代码引用这些类型

### 1.2 目标

完全移除 `System.Drawing.Common` 依赖，使用自定义轻量级值类型替代。

### 1.3 约束

- **零破坏性修改**：现有代码无需改动即可编译
- **渐进式迁移**：可逐文件移除 `using System.Drawing`
- **向后兼容**：隐式转换确保平滑过渡

## 二、设计方案

### 2.1 自定义值类型

创建 4 个 `readonly record struct`，位于 `Emuera.Headless/Primitives/` 命名空间：

| 类型 | 替代 | 关键成员 |
|------|------|----------|
| `EmuPoint` | `System.Drawing.Point` | `X`, `Y`, `Empty` |
| `EmuRectangle` | `System.Drawing.Rectangle` | `X`, `Y`, `Width`, `Height` |
| `EmuColor` | `System.Drawing.Color` | `R`, `G`, `B`, `A`, `FromArgb()`, `FromName()` |
| `EmuSize` | `System.Drawing.Size` | `Width`, `Height` |

### 2.2 隐式转换

每个类型实现双向隐式转换：

```csharp
// EmuColor 示例
public static implicit operator EmuColor(System.Drawing.Color c)
    => new(c.R, c.G, c.B, c.A);

public static implicit operator System.Drawing.Color(EmuColor c)
    => System.Drawing.Color.FromArgb(c.A, c.R, c.G, c.B);
```

**效果**：
- `EmuColor ec = System.Drawing.Color.Red;` ✅ 自动转换
- `System.Drawing.Color c = new EmuColor(255, 0, 0);` ✅ 自动转换
- 现有代码 **无需任何修改**

### 2.3 静态成员映射

#### Color 静态常量

| System.Drawing.Color | EmuColor |
|---------------------|----------|
| `Color.Black` | `EmuColor.Black` |
| `Color.White` | `EmuColor.White` |
| `Color.Red` | `EmuColor.Red` |
| `Color.Yellow` | `EmuColor.Yellow` |
| `Color.Gray` | `EmuColor.Gray` |
| `Color.Transparent` | `EmuColor.Transparent` |

#### Color 静态方法

| System.Drawing.Color | EmuColor |
|---------------------|----------|
| `Color.FromArgb(r, g, b)` | `EmuColor.FromArgb(r, g, b)` |
| `Color.FromArgb(a, r, g, b)` | `EmuColor.FromArgb(a, r, g, b)` |
| `Color.FromName(name)` | `EmuColor.FromName(name)` |

#### Point/Rectangle/Size

- `Point.Empty` → `EmuPoint.Empty`
- `new Point(x, y)` → `new EmuPoint(x, y)`
- `new Rectangle(x, y, w, h)` → `new EmuRectangle(x, y, w, h)`
- `new Size(w, h)` → `new EmuSize(w, h)`

#### 步骤 A4：实现 EmuColor

```csharp
// Emuera.Headless/Primitives/EmuColor.cs
namespace MinorShift.Emuera.Primitives;

internal readonly record struct EmuColor(byte R, byte G, byte B, byte A = 255)
{
    // 静态常量
    public static readonly EmuColor Empty = new(0, 0, 0, 0);
    public static readonly EmuColor Black = new(0, 0, 0);
    public static readonly EmuColor White = new(255, 255, 255);
    public static readonly EmuColor Red = new(255, 0, 0);
    public static readonly EmuColor Green = new(0, 128, 0);
    public static readonly EmuColor Blue = new(0, 0, 255);
    public static readonly EmuColor Yellow = new(255, 255, 0);
    public static readonly EmuColor Gray = new(128, 128, 128);
    public static readonly EmuColor Transparent = new(0, 0, 0, 0);

    // 静态工厂方法
    public static EmuColor FromArgb(int r, int g, int b)
        => new((byte)r, (byte)g, (byte)b);
    
    public static EmuColor FromArgb(int a, int r, int g, int b)
        => new((byte)r, (byte)g, (byte)b, (byte)a);
    
    public static EmuColor FromArgb(int argb)
        => new((byte)((argb >> 16) & 0xFF),
               (byte)((argb >> 8) & 0xFF),
               (byte)(argb & 0xFF),
               (byte)((argb >> 24) & 0xFF));

    public static EmuColor FromName(string name)
        => ColorNameMap.GetValueOrDefault(name.ToLowerInvariant(), Black);

    // 颜色名称映射（常用颜色）
    private static readonly Dictionary<string, EmuColor> ColorNameMap = new()
    {
        ["black"] = Black,
        ["white"] = White,
        ["red"] = Red,
        ["green"] = Green,
        ["blue"] = Blue,
        ["yellow"] = Yellow,
        ["gray"] = Gray,
        ["grey"] = Gray,
        ["transparent"] = Transparent,
        // ... 可按需扩展
    };

    // 隐式转换
    public static implicit operator EmuColor(System.Drawing.Color c)
        => new(c.R, c.G, c.B, c.A);
    
    public static implicit operator System.Drawing.Color(EmuColor c)
        => System.Drawing.Color.FromArgb(c.A, c.R, c.G, c.B);
}
```

### 阶段 B：渐进式迁移（1-2 天）

#### 策略

逐文件移除 `using System.Drawing`，替换为 `using MinorShift.Emuera.Primitives`。

#### 优先级

1. **Headless 自有代码**（`Headless/`、`UI/Game/Console/`）- 优先迁移
2. **共享代码**（`Shared/`）- 逐步迁移，可分批进行

#### 迁移示例

**Before**:
```csharp
using System.Drawing;

public void Method(Point p, Color c)
{
    var rect = new Rectangle(p.X, p.Y, 100, 100);
}
```

**After**:
```csharp
using MinorShift.Emuera.Primitives;

public void Method(EmuPoint p, EmuColor c)
{
    var rect = new EmuRectangle(p.X, p.Y, 100, 100);
}
```


## 四、风险评估

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 隐式转换性能开销 | 低 | record struct 是值类型，无堆分配 |
| Color.FromName 不完整 | 中 | 扩展 ColorNameMap 字典 |
| 共享代码修改冲突 | 低 | 分批迁移，避免大范围改动 |
| 遗漏 System.Drawing 引用 | 低 | 编译器会报错 |
