# Emuera.Headless 实施计划书

> 基于 SPEC_HEADLESS.md v1.0 | 日期：2026-06-08

---

## 总体策略

- 每个步骤独立可验证，完成一步再进入下一步
- 共享源码的修改全部使用 `#if HEADLESS` 条件编译，确保 WinForms 项目不受影响
- 每步完成后同时编译两个项目验证无回归

## Step 1: 创建项目骨架

**目标**：建立 `Emuera.Headless` 项目，能编译通过（即使编译结果是空壳）。

### 1.1 创建项目目录和 csproj

- 创建 `Emuera.Headless/` 目录
- 创建 `Emuera.Headless.csproj`：
  - `TargetFramework`: `net10.0`
  - `OutputType`: `Exe`
  - `DefineConstants`: `HEADLESS`
  - `AllowUnsafeBlocks`: true
  - `Nullable`: disable
  - 引用 `System.Drawing.Common` NuGet 包（提供 System.Drawing 类型，无需 Windows Desktop Runtime）
  - 引用 `Enums.NET`、`System.CommandLine` 包（与原项目一致）
  - 暂时不引用任何共享源码

### 1.2 创建最小 Program.cs

- 仅输出版本信息并退出
- 验证编译和运行

### 验收

```bash
dotnet build Emuera.Headless/Emuera.Headless.csproj -c Debug
Emuera.Headless.exe
# → 输出版本信息，退出码 0
```

### 5.2 创建 `HeadlessStringMeasure.cs`

替代 `UI/Game/StringMeasure.cs`，放在 `Emuera.Headless/` 目录下。

```csharp
using System;
using System.Drawing;
using MinorShift.Emuera.Runtime.Config;

namespace MinorShift.Emuera.UI.Game;

internal sealed class StringMeasure : IDisposable
{
    private readonly float _charWidth;

    public StringMeasure()
    {
        // 估算：字号的一半作为平均字符宽度（等宽字体近似）
        _charWidth = Config.FontSize / 2f;
    }

    public int GetDisplayLength(ReadOnlySpan<char> chars, Font f)
    {
        return GetDisplayLength(chars.ToString(), f);
    }

    public int GetDisplayLength(string s, Font font)
    {
        if (string.IsNullOrEmpty(s))
            return 0;
        // 简单估算：每个字符按平均宽度计算
        // CJK 字符宽度约为等宽字体的 2 倍
        int width = 0;
        foreach (char c in s)
        {
            width += IsWideChar(c) ? 2 : 1;
        }
        return (int)(width * _charWidth);
    }

    private static bool IsWideChar(char c)
    {
        return (c >= 0x2E80 && c <= 0x9FFF)
            || (c >= 0xAC00 && c <= 0xD7AF)
            || (c >= 0xF900 && c <= 0xFAFF)
            || (c >= 0xFF01 && c <= 0xFF60)
            || (c >= 0xFFE0 && c <= 0xFFE6);
    }

    public void Dispose() { }
}
```

### 5.3 在 csproj 中配置替代

确保 `Emuera.Headless/` 下的 `Dialog` 和 `StringMeasure` 优先于共享源码中的同名类。
- `HeadlessDialog.cs` 中的 `Dialog` 类在 `Emuera.Headless/` 命名空间下，会覆盖共享的 `UI/Dialog.cs`
- 需要在 csproj 中排除共享的 `UI/Dialog.cs`

```xml

<Compile Remove="..\Emuera\UI\Game\StringMeasure.cs" />
```

## Step 6: 完善 Program.cs 入口

**目标**：实现完整的 `--headless` 和 `--server` 入口逻辑。

### 6.1 Program.cs 完整实现

参考原 `Emuera/Program.cs` 中的 `RunHeadless()` 和 `RunServer()` 逻辑，但：
- 不包含 WinForms 相关代码
- 不包含 `Application.Run()`、`Icon` 加载等
- 不包含 `FormWindowState`、`ApplicationConfiguration.Initialize()` 等

```csharp
using System;
using System.CommandLine;
using System.CommandLine.Parsing;
using System.Globalization;
using System.IO;
using MinorShift.Emuera.GameView;
using MinorShift.Emuera.Runtime.Config;
using MinorShift.Emuera.Runtime.Config.JSON;
using MinorShift.Emuera.Server;
using MinorShift.Emuera.UI.Game;

namespace MinorShift.Emuera.Headless;

static class Program
{
    static void Main(string[] args)
    {
        System.Text.Encoding.RegisterProvider(System.Text.CodePagesEncodingProvider.Instance);
        CultureInfo.CurrentCulture = CultureInfo.InvariantCulture;
        CultureInfo.DefaultThreadCurrentCulture = CultureInfo.InvariantCulture;

        // 解析参数
        var rootCommand = new RootCommand("Emuera.Headless");
        var headlessOption = new Option<bool>("--headless", "无头模式");
        var serverOption = new Option<bool>("--server", "服务器模式");
        var portOption = new Option<int>("--port", () => 8080, "监听端口");
        var exeDirOption = new Option<string>("--ExeDir", "游戏目录");

        rootCommand.AddOption(headlessOption);
        rootCommand.AddOption(serverOption);
        rootCommand.AddOption(portOption);
        rootCommand.AddOption(exeDirOption);

        var result = rootCommand.Parse(args);
        var headless = result.GetValueForOption(headlessOption);
        var server = result.GetValueForOption(serverOption);
        var port = result.GetValueForOption(portOption);
        var exeDir = result.GetValueForOption(exeDirOption);

        // 初始化核心配置
        InitializeCore(exeDir);

        if (server)
            RunServer(port);
        else
            RunHeadless();
    }

    static void InitializeCore(string? exeDir)
    {
        // 设置目录路径
        if (exeDir != null)
            SetDirPaths(exeDir);

        ConfigData.Instance.LoadConfig();
        JSONConfig.Load();

        // 加载语言文件
        Runtime.Utils.EvilMask.Lang.LoadLanguageFiles();
        Runtime.Utils.EvilMask.Lang.SetLanguage();

        // 验证目录
        if (!Directory.Exists(CsvDir))
        {
            Console.Error.WriteLine($"[error] CSV 目录不存在: {CsvDir}");
            Environment.Exit(1);
        }
        if (!Directory.Exists(ErbDir))
        {
            Console.Error.WriteLine($"[error] ERB 目录不存在: {ErbDir}");
            Environment.Exit(1);
        }
    }

    static void RunHeadless()
    {
        Console.Error.WriteLine($"[headless] Emuera 无头模式启动");
        Console.Error.WriteLine($"[headless] 工作目录: {ExeDir}");
        Console.Error.WriteLine($"[headless] 协议类型: {(Console.IsInputRedirected ? "JSONL (管道)" : "CLI (终端)")}");

        var ui = new HeadlessConsole();
        var console = new EmueraConsole(ui);
        console.Initialize().Wait();

        var protocol = console.AgentBridge;
        if (protocol != null)
        {
            while (!protocol.IsStopped)
                Thread.Sleep(100);
        }
        else
        {
            Console.Error.WriteLine("[headless] 未检测到输入管道");
            Environment.Exit(1);
        }
    }

    static void RunServer(int port)
    {
        Console.Error.WriteLine($"[server] Emuera 服务器模式启动，端口: {port}");

        using var server = new HttpGameServer(port);
        server.Start();

        Console.Error.WriteLine("[server] 按 Enter 键停止服务器...");
        Console.ReadLine();
    }

    // 目录路径（与原 Program.cs 相同）
    public static string ExeDir { get; private set; }
    public static string CsvDir { get; private set; }
    public static string ErbDir { get; private set; }
    public static string DebugDir { get; private set; }
    public static string DatDir { get; private set; }
    public static string ContentDir { get; private set; }
    public static string SoundDir { get; private set; }
    public static string FontDir { get; private set; }

    public static bool IsHeadlessMode => true;

    static Program()
    {
        var baseDirectory = AppContext.BaseDirectory;
        if (Directory.Exists(Path.Combine(baseDirectory, "Data", "erb")))
            baseDirectory = Path.Combine(baseDirectory, "Data");
        SetDirPaths(baseDirectory);
    }

    [System.Diagnostics.CodeAnalysis.MemberNotNull(nameof(ExeDir), nameof(CsvDir), nameof(ErbDir), nameof(DebugDir), nameof(DatDir), nameof(ContentDir), nameof(SoundDir), nameof(FontDir))]
    static void SetDirPaths(string exeDir)
    {
        ExeDir = Path.GetFullPath(new DirectoryInfo(exeDir).FullName + Path.DirectorySeparatorChar);
        CsvDir = Path.Combine(ExeDir, "csv") + Path.DirectorySeparatorChar;
        ErbDir = Path.Combine(ExeDir, "erb") + Path.DirectorySeparatorChar;
        DebugDir = Path.Combine(ExeDir, "debug") + Path.DirectorySeparatorChar;
        DatDir = Path.Combine(ExeDir, "dat") + Path.DirectorySeparatorChar;
        ContentDir = Path.Combine(ExeDir, "resources") + Path.DirectorySeparatorChar;
        SoundDir = Path.Combine(ExeDir, "sound") + Path.DirectorySeparatorChar;
        FontDir = Path.Combine(ExeDir, "font") + Path.DirectorySeparatorChar;
    }
}
```

### 6.2 处理命名空间冲突

原 `Program.cs` 在 `MinorShift.Emuera` 命名空间下，其他文件通过 `Program.ExeDir` 等访问静态成员。
无头版本的 `Program` 需要在相同命名空间下，或通过其他方式提供这些静态成员。

**方案**：将无头 `Program.cs` 放在 `MinorShift.Emuera` 命名空间下，确保 `Program.ExeDir` 等静态成员可被共享代码访问。

## Step 7: 编译调试与修复

**目标**：修复所有编译错误，直到无头项目能成功编译。

### 7.1 预期问题类型

| 问题类型 | 示例 | 修复方式 |
|---------|------|---------|
| 缺少 using | 引用了 `System.Windows.Forms` 的类型 | 添加 `#if !HEADLESS` 包裹 using |
| 缺少类型 | `MainWindow`、`WinFormsConsole` 等在排除文件中 | 检查引用路径，确认是否真的需要 |
| 命名空间不匹配 | `Program` 类的静态成员访问 | 确保命名空间一致 |
| 缺少 NuGet 包 | `System.Text.Json` 等 | 在 csproj 中添加 |
| 嵌套类型引用 | `ConsoleButtonString` 内部引用了图片类型 | 可能需要排除或条件编译 |

### 7.2 修复策略

1. 运行 `dotnet build`，收集所有错误
2. 按文件分组，逐个修复
3. 每修复一批后重新编译验证
4. 重复直到零错误
