# Emuera.Headless 无头独立版本规格书

> 版本：v1.0 | 日期：2026-06-08

---

## 一、背景与目标

### 1.1 现状

当前项目已完成一轮大重构（ROADMAP Phase 1-6），核心成果包括：

- `IConsoleUI` 接口 + `HeadlessConsole` 空实现，让 `EmueraConsole` 不再直接依赖 WinForms 窗体
- `AgentProtocolBase` / `AgentJsonlProtocol` / `AgentCliProtocol` 协议层已解耦，支持管道和终端两种输入方式
- `SessionIO` 抽象 + `HttpGameServer` 服务器模式，支持多会话 HTTP API
- `Program.cs` 支持 `--headless` 和 `--server` 参数

**但存在一个根本问题**：所有代码仍然编译在同一个 `Emuera.csproj` 中，该项目标记为 `net10.0-windows` + `UseWindowsForms=true`。这意味着：

- 即使只运行 `--headless` 模式，也必须安装 .NET Windows Desktop Runtime
- 编译产物无法在无 GUI 的 Windows Server Core 或未来可能的 Linux 环境下运行
- Runtime 层中散布着 `MessageBox.Show`、`Application.DoEvents`、`Clipboard.SetDataObject` 等 WinForms 调用，虽然无头路径不会走到，但编译时仍被绑定

### 1.2 目标

构建一个**完全不依赖 WinForms 的独立可执行文件** `Emuera.Headless`，具备以下特性：

- 不引用 `System.Windows.Forms`，不需要 Windows Desktop Runtime
- 保留 `System.Drawing`（Color/Bitmap/Font/Rectangle 等类型在 Runtime 层广泛使用，替换代价极高）
- 仅支持 `--headless`（管道/终端）和 `--server`（HTTP 多会话）两种运行模式
- 与原有 WinForms 版本共享 Runtime 核心代码，通过最小改动实现兼容

## 三、目标架构

```
Emuera.sln
│
├── Emuera/ ──────────── 原有 WinForms 项目（不改动或极少改动）
│   └── Emuera.csproj (net10.0-windows, UseWindowsForms=true)
│       └── 包含所有文件，行为不变
│
└── Emuera.Headless/ ─── 新增无头独立项目
    ├── Emuera.Headless.csproj (net10.0, 无 UseWindowsForms)
    ├── Program.cs ──────── 仅 --headless / --server 入口
    │
    └── 通过 <Compile Include> 引用共享源码：
        ├── Runtime/ ────── 共享（含少量条件编译修改）
        ├── Server/ ────── 共享（无需修改）
        ├── UI/Game/ ───── 部分共享（排除 WinForms 专用文件）
        └── GlobalStatic.cs ── 共享
```

### 3.2 需要替换/新增的文件

| 替换目标 | 方案 |
|---------|------|
| `UI/Dialog.cs` | 新建 `HeadlessDialog.cs`：所有 `Show` 方法改为 `Console.Error.WriteLine` |

| `Clipboard.cs` 中的剪贴板操作 | 无头模式下跳过（`ClipboardProcessor` 在无头构造函数中已为 null） |

## 四、详细改动清单

### 4.1 新建文件

| 文件 | 说明 |
|------|------|
| `Emuera.Headless/Emuera.Headless.csproj` | 项目文件：`net10.0`，引用 `System.Drawing`，不引用 WinForms |
| `Emuera.Headless/Program.cs` | 入口：解析参数，走 `RunHeadless()` 或 `RunServer()` |

### 4.2 新建替代文件

| 文件 | 替代目标 | 说明 |
|------|---------|------|
| `Emuera.Headless/HeadlessDialog.cs` | `UI/Dialog.cs` | 所有弹窗改为 `Console.Error.WriteLine` |
| `Emuera.Headless/HeadlessStringMeasure.cs` | `UI/Game/StringMeasure.cs` | 文本宽度估算，不依赖 `Graphics` |

### 4.3 修改共享源码（条件编译）

所有对共享源码的修改都使用 `#if HEADLESS` 条件编译，确保 WinForms 项目不受影响。

| 文件 | 改动 |
|------|------|
| `Runtime/Utils/Sys.cs` | `Application.ProductVersion` → `#if HEADLESS` 用 `Assembly` API，`#else` 保持原样 |
| `Runtime/Config/Config.cs` | `MessageBox.Show(...)` → `#if HEADLESS` 用 `Console.Error.WriteLine`，`#else` 保持原样 |
| `Runtime/Script/Statements/Instraction.Child.cs` | 同上，2 处 `MessageBox.Show` |
| `Runtime/Script/Statements/Variable/VariableEvaluator.cs` | 同上，1 处 `MessageBox.Show` |
| `Runtime/Utils/WebPWrapper.cs` | 同上，1 处 `MessageBox.Show` |
| `Runtime/Script/Statements/Clipboard.cs` | `#if HEADLESS` 跳过剪贴板操作 |
| `Runtime/Script/Loader/ErhLoader.cs` | `Application.DoEvents()` → `#if HEADLESS` 空操作 |
| `Runtime/Script/Loader/ErbLoader.cs` | 同上 |

### 4.4 Emuera.Headless.csproj 关键配置

```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <TargetFramework>net10.0</TargetFramework>
    <!-- 注意：不设置 UseWindowsForms -->
    <OutputType>Exe</OutputType>
    <DefineConstants>HEADLESS</DefineConstants>
    <Nullable>disable</Nullable>
    <AllowUnsafeBlocks>true</AllowUnsafeBlocks>
  </PropertyGroup>

  <ItemGroup>
    <!-- 保留 System.Drawing，仅 Windows 可用 -->
    <Using Remove="System.Windows.Forms" />
  </ItemGroup>

  <!-- 共享源码引用 -->
  <ItemGroup>
    <Compile Include="..\Emuera\Runtime\**\*.cs" />
    <Compile Include="..\Emuera\Server\**\*.cs" />
    <Compile Include="..\Emuera\GlobalStatic.cs" />
    <!-- UI/Game 中需要的文件 -->
    <Compile Include="..\Emuera\UI\Game\IConsoleUI.cs" />
    <Compile Include="..\Emuera\UI\Game\HeadlessConsole.cs" />
    <Compile Include="..\Emuera\UI\Game\EmueraConsole*.cs" />
    <Compile Include="..\Emuera\UI\Game\Agent*.cs" />
    <!-- ... 其他需要的文件 -->
  </ItemGroup>

  <!-- 排除 WinForms 专用文件 -->
  <ItemGroup>
    <Compile Remove="..\Emuera\Runtime\Utils\Sound.WMP.cs" />
    <Compile Remove="..\Emuera\Runtime\Utils\Sound.NAudio.cs" />
    <Compile Remove="..\Emuera\Runtime\Utils\NAudio_LoopStream.cs" />
    <Compile Remove="..\Emuera\Runtime\Utils\WinInput.cs" />
  </ItemGroup>
</Project>
```

| 场景 | 当前方式 | 改造后 |
|------|---------|--------|

| 无头管道模式 | `Emuera.exe --headless` | `Emuera.Headless.exe --headless` |

## 六、验证标准

### 6.1 编译验证

```bash
# 无头项目编译通过（不依赖 WinForms）
dotnet build Emuera.Headless/Emuera.Headless.csproj -c Debug

# 原有 WinForms 项目编译不受影响
dotnet build Emuera/Emuera.csproj -c Debug-NAudio
```

### 6.2 功能验证

```bash
# 1. 无头管道模式
echo '{"type":"input","value":""}' | Emuera.Headless.exe --headless
# → 输出初始回合 JSON，进程退出码 0

# 2. HTTP 服务器模式
Emuera.Headless.exe --server --port 8080
# → stderr 输出监听日志
# → curl 能正常创建会话、提交输入、获取回合

# 3. Python 网关
python mcp_relay.py
# → MCP 工具调用正常
```

### 6.3 回归验证

```bash
# WinForms 版本不受影响
Emuera.exe
# → 正常出现窗口，游戏功能正常
```

## 七、不做的事情

| 不做 | 原因 |
|------|------|
| 移除 System.Drawing 依赖 | Color/Bitmap/Font/Rectangle 在 Runtime 层广泛使用，替换代价极高，且 System.Drawing 在 Windows 上无需额外安装 |
| 跨平台编译 (Linux/macOS) | System.Drawing 仍为 Windows-only，需等后续 Phase |
| Web 前端 | 依赖服务器模式稳定后 |
| 修改原有 Emuera.csproj | 保持 WinForms 版本完全不变，所有改动通过条件编译隔离 |
| 图片渲染功能 | 无头模式不需要，Image/ 目录下的文件不包含在无头项目中 |

## 八、风险与回退

| 风险 | 缓解 |
|------|------|
| 共享源码的条件编译影响 WinForms 版本 | 每次修改后同时编译两个项目验证 |
| StringMeasure 估算宽度与实际不一致 | 无头模式只输出文本，不涉及像素渲染，估算值不影响功能 |
| 遗漏 WinForms 依赖导致编译失败 | 去掉 UseWindowsForms 后编译即可暴露所有问题 |
| EmueraConsole 中仍有隐藏的 WinForms 引用 | 编译时逐个修复，预计改动量很小 |

回退方案：如果无头版本出现问题，直接删除 `Emuera.Headless/` 目录，原有 `Emuera.exe` 不受任何影响。
